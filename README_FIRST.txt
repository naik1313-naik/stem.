SMARTCLASS BUDDY — QUICK START

1. Extract this folder somewhere simple, for example C:\Projects\SmartClass-Buddy.
2. Open PowerShell in the extracted SmartClass-Buddy folder.
3. Run:
     cd apps\web
     npm.cmd install
     npm.cmd test
     npm.cmd run build
     npm.cmd run dev
4. Open http://127.0.0.1:5173
5. Choose a group, make a prediction, then enter the Workbench.

For desktop/mobile screenshots and the full challenge/offline browser tests, see README.md → Browser tests and screenshots.
The project includes the original FastAPI health-only backend in apps\api; the student lesson itself does not depend on it.
